Tidify protocol docs

A non-custodial Solana program that recovers usable value from small token balances — by swapping, burning, or closing SPL Token and Token-2022 accounts.

Overview

Tidify runs entirely on Solana mainnet. The web app is a thin client: it reads your token accounts, prices them, proposes an action per position, and builds transactions that your wallet signs. There is no backend and no custody — user funds never pass through a Tidify-controlled account.

The protocol has two derived accounts: the config PDA (fee configuration and authorities) and the vault PDA (collects protocol fees only — never user funds). Both are derived from the program ID and verifiable on-chain.

How it works

1
Connect or paste a wallet.

Reads every SPL Token and Token-2022 account on Solana mainnet. No signature is needed to preview.

2
Scan and price.

Every balance is priced in USD via Jupiter; friendly names come from the curated token list and on-chain metadata.

3
Review the plan.

Each position gets a proposed action — swap, burn, or close — with value, fees, rent recovery, and estimated net recovery shown.

4
Approve one batch.

You select exactly which accounts to touch; destructive actions are never pre-selected. Your wallet signs the real transactions.

What else you pay

  • Solana network fee — the transaction fee set by the network (typically ~0.000005 SOL + any priority fee you add).
  • Jupiter platform fee — the swap platform fee charged by the route when a swap is used.

Fee safety: on the swap path the realized fee is enforced on-chain against your approved ceiling — a route can never take more than the maximum you saw in the preview. The estimated net recovery is shown per position before you approve anything.

Token support

  • Standard SPL Token and Token-2022 accounts on Solana mainnet.
  • Swaps require a working Jupiter route for the exact balance; small routes are preferred so transactions fit the 1232-byte wire limit.
  • Tokens without a usable route are burned only when the destroyed value is provably no greater than the cost of burning.
  • Non-transferable, unsupported, or unverified tokens are never swapped — they are labeled and can be closed to reclaim rent.
  • The selected output currency (USDC or USDT) is never treated as dust.
  • Rent reclaimed from closed token accounts is returned by Solana in SOL. Tidify keeps it as SOL to avoid an additional swap, network fee, and slippage.

Security

  • Non-custodial. Funds never enter a Tidify-controlled account; the vault only receives protocol fees.
  • User approval. Every account is explicitly selected; destructive actions require manual checks and are never pre-selected.
  • On-chain fee caps. Fee rates and ceilings live in the config account; the swap path enforces the user's ceiling on the realized fee.
  • Read-only previews. The guest preview performs no writes.
