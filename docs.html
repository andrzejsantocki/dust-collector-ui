Tidify protocol docs

Tidify is a non-custodial Solana program that helps you recover usable value from small token balances (dust) by swapping, burning, or closing SPL Token and Token-2022 accounts.

Program

Program ID: H5ix9UP5hx3k5W3nu1rMdbDgo5Ahb9Q8RANLdoiXYCgw
View on Orb: https://orb.helius.dev/program/H5ix9UP5hx3k5W3nu1rMdbDgo5Ahb9Q8RANLdoiXYCgw

The protocol has two derived accounts: a config PDA holding the fee configuration and authorities, and a vault PDA that receives protocol fees. Funds belonging to users never pass through the vault — only the protocol fee does.

On-chain fee configuration

The config account is the source of truth for fees. The web app reads it before every preview and refuses to build anything when it cannot be read.

FieldMeaning
closeFeeBpsProtocol fee in basis points for closing an account (bounded by the min/max in lamports).
closeMinFeeLamports / closeMaxFeeLamportsFloor and ceiling of the close fee per account.
swapFeeBps / swapMaxFeeBpsProtocol fee rate and ceiling for the swap-and-close path.
adminAuthority that can update the configuration.
protocolVaultAccount that collects protocol fees.
pausedWhen paused, the app blocks transaction execution.

Fee safety: the realized fee on the swap path is enforced on-chain against the user's ceiling — a route cannot take more than the maximum you approved.

Token support

  • SPL Token and Token-2022 accounts on Solana mainnet.
  • Swaps require a working Jupiter route for the exact balance (small routes are preferred so transactions fit the 1232-byte wire limit).
  • Tokens without a usable swap route are burned only when the destroyed value is provably no greater than the cost of burning.
  • Non-transferable, unsupported, or unverified tokens are never swapped; they are labeled and can be closed to reclaim rent.
  • The selected output currency (USDC, USDT, or SOL) is never treated as dust.

How the preview works

  1. Read every token account of the wallet (SPL + Token-2022).
  2. Price each balance in USD via Jupiter price feeds.
  3. Resolve friendly names from the curated Jupiter list and on-chain metadata (Metaplex / Token-2022 extensions).
  4. Fetch swap quotes for every swappable balance; classify each position as swap, burn, or close.
  5. Show per-position economics: value, expected swap output, rent recovered, maximum protocol fee, and estimated net recovery.

The guest preview on the main page runs this exact pipeline for any address without a wallet connection — nothing is signed or sent.

Wallets

Any wallet supported by the Solana wallet-adapter ecosystem works (Phantom, Solflare, and similar). Transactions are built, simulated, and sent from your browser; Tidify never holds your keys.

Privacy

All reads happen from your browser directly against Solana RPC endpoints and public APIs. There is no Tidify backend and no tracking.
